# План реализации Telegram Mini App для салонов красоты

## Backend (FastAPI)
1. Создать файл `web_app_server.py` в корне проекта.
2. Реализовать валидацию initData через `aiogram.utils.web_app.safe_parse_webapp_init_data`.
   - Взять токен бота из `app.config`.
3. Создать эндпоинт `POST /api/get_services`:
   - Принимает `initData` и `tenant_id` (из start_param).
   - Валидирует пользователя через initData.
   - Если пользователя нет в базе, создает его с ролью `client`, привязывая к `tenant_id`.
   - Возвращает список услуг (`Service`), фильтруя по `tenant_id`.
4. Добавить CORS-middleware для работы с фронтендом на `localhost:5173`.
5. Обеспечить асинхронность во всех операциях с БД (используя `app.database.engine`).
6. Использовать логирование ошибок через `logging`.

## Frontend (React + Vite)
1. Создать структуру проекта React + Vite в папке `frontend/`.
2. Установить зависимости: `@twa-dev/sdk`, `tailwindcss`, и т.д.
3. Логика:
   - При загрузке извлекать `start_param` (формат `tenant_123`) через `WebApp.initDataUnsafe.start_param`.
   - Выделять ID салона из `start_param`.
4. UI/UX:
   - Использовать системные цвета Telegram (`--tg-theme-bg-color`, `--tg-theme-text-color` и т.д.).
   - Главный экран: Заголовок `"Запис до [Назва салону]"`, список карточек услуг.
   - Компонент `ServiceCard`: Название, цена, длительность.
   - Использовать `tg.HapticFeedback.impactOccurred('medium')` при выборе услуги.
   - Реализовать `MainButton` через `window.Telegram.WebApp.MainButton` для подтверждения выбора.
5. Весь интерфейс и сообщения об ошибках должны быть на украинском языке.

## Интеграция с Ботом
1. В файле `handlers/start.py` (или создать, если не существует) обновить логику команды `/start`.
2. Кнопка для открытия Mini App должна содержать URL с параметром: `https://your-domain.com?startapp=tenant_{tenant_id}`.
   - Здесь `tenant_id` - это ID салона, к которому привязан пользователь (или из контекста, если пользователь выбирает салон).

## Технические требования
- Весь код должен быть асинхронным (async/await).
- Использовать библиотеку `logging` для логирования ошибок.
- Безопасность: Никаких запросов к БД без успешной проверки подписи `initData`.

## Последовательность выполнения
1. Backend: Создать `web_app_server.py` и настроить FastAPI.
2. Frontend: Инициализировать проект React и реализовать основные компоненты.
3. Интеграция: Обновить бота для отправки кнопки открытия Mini App.
4. Тестирование: Проверить взаимодействие между ботом, Mini App и backend.

## Файлы для создания/изменения
- Backend: `web_app_server.py` (новый)
- Frontend: вся папка `frontend/` (новая)
- Bot: `app/bot/handlers/start.py` (новый или существующий)
- Возможно, потребуется добавить роутер для веб-апп в основное приложение бота (если используется диспетчер).
